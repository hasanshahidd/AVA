Discovery pipeline · what runs, in order

1

Network sweep

Built
executor.py · _sweep_host()

Every host probed independently — TCP ports, protocol fingerprint (SNMP/DNS/banners), and the scanner's own ARP table for silent hosts. Classifies routers / switches / printers / hosts. No links between devices yet — this is the gap.

2

Observations

Built
DiscoveryObservation.raw{}

One evidence row per device: ip, mac, open_ports, device_type, os_guess, vendor. Lands as pending — nothing is an asset yet.

3

Resolve → Inventory

Built
resolver.py · resolve_run()

Observations become canonical ITAsset rows (merge / create / review). Every device now has a stable id to hang edges off.

4

Post-run link builders

Pattern exists
executor.py · execute_run() → link_domain_hierarchy()

After each run, builders write edges idempotently. DNS lineage already does this (subdomain_of). Network topology is the same shape — a new sibling builder.

domain_hierarchy

network_topology

New · P1

connects_to / member_of — subnet + gateway.

5

Edge store

Reused as-is
AssetRelationship (grc_asset_relationships)

Directed, typed edges. The vocabulary already includes connects_to and member_of — no schema change. Edges show on each device's Relationships tab for free.

6

SNMP neighbor walks

Phase 2
snmp.py · add LLDP / CDP / bridge-FDB walks

Reuses the existing GETNEXT machinery (already walks ifTable). Reads the switches themselves for measured links: switch↔switch↔router and endpoint-MAC→switch-port. This is the true "PC plugged into that switch." Needs SNMP read on the gear (campaigns already collect communities).

7

Topology API + Map view

Phase 3
/discovery/topology → React Flow "Network map" tab

New endpoint returns {nodes, edges} from AssetRelationship. Rendered with React Flow — the same graph stack already used by the asset TrajectoryMap. New tab on the discovery page.

Where the links come from

Three signals, cheapest first.

P1 · free
Subnet membership

Every IP → its CIDR. All hosts on 10.0.0.0/24 share a broadcast domain → member_of a subnet node. Zero new probing.

P1 · free
Default gateway

The device fingerprinted as router/firewall (or sitting at .1) is the subnet's uplink → every host connects_to it. Draws the star.

P2 · SNMP
Neighbor + bridge tables

LLDP / CDP give switch↔switch↔router. The bridge FDB maps each endpoint MAC to a switch port — the real PC→switch edge.

The honest limit: true "which switch port" is only knowable from the gear over SNMP. Phase 1 gives a correct router/subnet map from data already in hand; Phase 2 upgrades those edges to measured wherever a switch answers SNMP.

Reused, not rebuilt
